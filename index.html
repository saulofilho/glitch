Deck

Plays in the browser. Computer keyboard, MIDI, 64 steps.

FM-1 panel

FM-1 panel in the browser. It sounds once web/build_web.sh has been run.

Editor

Sounds, samples, and a backup of the unit, in Chrome or Edge.

On the FM-1, the name on the screen is CYB!RM.

  1. 1

    Build build/cybirm.fwsc with ./build.sh --name cybirm.fwsc (JieLi toolchain required).

  2. 2

    Install on your FM-1 with python3 tools/fm1_install.py build/cybirm.fwsc while the unit is connected over USB. The Firmware Hub is optional — use it only if you want to publish firmware for others to install in the browser.

  3. 3

    Colour 1 on the unit is cyan. The added scales are Insen, Hirajoshi, Iwato, and whole tone.
